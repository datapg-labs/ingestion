# Projects

Learner projects, one directory each. Every project has a `README.md` that starts like
this — the `Authors:` line is what decides who can change the project:

```markdown
# BTC price alerts

Authors: @your-github-user

What it does, where the data comes from, and what you learned building it.
```

Start one by copying `../reference/_template/` here under a name that says what it does.
To work on an existing project, open a pull request that only adds your handle to its
`Authors:` line. See [CONTRIBUTING.md](../CONTRIBUTING.md).
